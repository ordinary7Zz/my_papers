# ThyroidAgent Fig 1 & Fig 2 重设计规格（横向版）

本文档基于当前两图的视觉风格，重新设计为**横向布局**（宽 > 高），以降低高宽比，更适合论文双栏排版。

---

## 风格基础（保留不变）

- 浅色圆角矩形模块
- 装饰图标（数据库柱状图、机器人、齿轮、放大镜、剪贴板、雪花）
- 调色板：浅蓝（输入/数据）、浅绿（特征/简单路径）、浅橙（决策/输出）、浅紫（专家模块）、浅黄（复杂路径）、浅红（LLM）
- 数据流箭头连接模块
- 底部横条标识 "ThyroidAgent"

## Fig 1 新设计：Dual-Path Cascade Architecture（横向）

### 整体布局

**横向单行**，从左到右分为 5 个区域：

```
[Image] → [Expert Pool] → [Consensus?] → ┌─ Path A (上) ──→ [Output]
                                          └─ Path B (下) ──→ [Output]
```

### 详细布局（左→右）

```
┌──────────┐   ┌──────────────────────┐   ┌───────────┐   ┌─────────────────────┐   ┌────────┐
│          │   │   Expert Pool        │   │ Consensus │   │   Path A (上排)     │   │        │
│ Ultrasound│  │ ┌────────┐ ┌───────┐ │   │   Check   │   │ Anchor-guided       │   │ Final  │
│  Image   │──→│ │Cls Exp │ │Seg Exp│ │──→│    ?      │──→│ SegSelect → CCA     │──→│ Output │
│  (icon)  │   │ │3 models│ │5 mod- │ │   │ (diamond) │   │                     │   │ Mask + │
│          │   │ │        │ │els    │ │   │           │   ├─────────────────────┤   | Label  │
└──────────┘   │ └────────┘ └───────┘ │   └─────┬─────┘   │   Path B (下排)     │   │        │
               └──────────────────────┘         │         │ Radiomics Judge →   │   └────────┘
                                                │ YES     │ Pre-filter →        │
                                                ↓ NO      │ SegSelect → CCA →   │
                                           (split)        │ AutoGluon →         │
                                                         │ Reconcile →         │
                                                         │ [LLM if ambiguous]  │
                                                         └─────────────────────┘
```

### 模块详情

**① 输入区（最左）**：
- 超声图像缩略图（保留现有图标）
- 标签 "Ultrasound Image"
- 浅蓝背景

**② 专家池区**：
- 一个大圆角矩形，内部分上下两行：
  - 上行 "Cls Experts"（浅紫）：3 个小图标代表 DINOv3-Multitask / MedSigLIP / BiomedCLIP
  - 下行 "Seg Experts"（浅紫）：5 个小图标代表 DINOv3-UNet / TransUNet / MedSegX / MedSAM2 / UltraFedFM
- 标注 "Parallel Inference"
- 两个输出箭头：分类概率 → 共识检查；mask 候选 → 路径选择

**③ 共识检查区**：
- 菱形决策框，浅橙背景
- 文字 "Consensus? (Cls agree)"
- 两个输出箭头：YES 向上→Path A，NO 向下→Path B

**④ 双路径区**（核心，占图宽约 40%）：
- **Path A（上半部，浅绿背景）**：
  - "Anchor-guided SegSelect" → "CCA Refine" → 输出箭头
  - 标注 "Path A: Consensus Shortcut"
  - 标注 "Cls = Anchor (bypass AutoGluon & LLM)"
  
- **Path B（下半部，浅黄背景）**：
  - 水平排列 5 个子模块：
    1. "GT-trained Radiomics Judge"（天平图标，浅蓝紫）
    2. "Pre-filter"（浅黄）
    3. "SegSelect"（浅黄）
    4. "CCA Refine"（浅黄）
    5. "AutoGluon Cls"（浅紫）
  - 下方接 "Reconcile" 模块（浅橙）
    - 内部 3 个分支： Agree → Rule | High-conf → Rule | Ambiguous → LLM
    - LLM 模块用机器人图标 + 虚线框（浅红），标注 "Only ~5%"
  - 标注 "Path B: Dispute Resolution"

**⑤ 输出区（最右）**：
- 数据库柱状图图标
- 标签 "Final Output: Seg Mask + Cls Label"
- 浅橙背景

### 尺寸建议

- 宽高比约 **16:6**（宽 1600px × 高 600px）
- Path B 子模块用小尺寸圆角矩形横向紧密排列
- Path A 和 Path B 上下并行，共用左右入口和出口

### 视觉细节

**上行（Training）颜色**：
- 浅蓝色：数据集相关

- 浅橙色：特征/注册
- 浅紫色：Experts Zoo
- 浅黄色：Metadata Registry
- 浅蓝紫色：GT-trained Radiomics Judge（突出"裁判"地位）

**下行（Inference）颜色**：
- Phase 1-2（并行推理）：浅紫色

- Phase 4（Path B）：浅黄色
- GT-trained Radiomics Judge：浅蓝紫色
- Phase 5 Reconcile：浅橙色
- LLM 仲裁：浅红色 + 虚线框
- 输出：浅橙

**装饰元素**：
- 超声图像图标（输入）
- 数据库柱状图（数据集 + 输出）
- 齿轮图标（训练）
- 雪花图标（metadata）
- 天平/盾牌图标（Radiomics Judge）
- 机器人图标（LLM）

### 关键文本标签

**上行**：
- "GT Masks → PyRadiomics → AutoGluon → Radiomics Judge"
- 副标题："Dual-purpose: assess mask quality + classify"

**下行**：
- "PHASE 1: Parallel Seg Inference"

### 尺寸建议

- 宽高比约 **16:5**（宽 1600px × 高 500px 上行 + 500px 下行 = 1000px）
